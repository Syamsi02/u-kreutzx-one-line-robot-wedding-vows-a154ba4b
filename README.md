One line of wedding vows for a robot couple, at most 160 characters, written to make a judge laugh: a classic vow twisted through co-processors, low batteries, and a factory reset. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the vow to `/output/entry.txt` (one line, 136 characters, no trailing newline).
